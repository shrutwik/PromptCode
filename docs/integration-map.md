## Auth model

- Bearer `Authorization` from `sessionStorage` (`pc_token` / migrated `access_token`).
- Optional `X-Session-Token` (`owner_token`) for session ownership.
- Optional HttpOnly cookies when `PROMPTCODE_AUTH_COOKIE_ENABLED`.
- Cross-user session access → **404** (no existence leak). Unauth → **401**.

## Challenge registry

- Source of truth: `challenges/interview-registry.json` (**10** challenges).
- Hidden: `SOLUTION.md`, interviewer metadata, audit markdown — blocked by registry helpers.

## Runners / AI

- `PROMPTCODE_RUNNER=local|docker` → `get_challenge_runner()`.
- AI: empty/missing key → mock provider; production uses OpenAI settings.
