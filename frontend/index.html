how it works

Solve real problems.
Get scored on how you solve them.

Unlike traditional coding challenges, PromptCode evaluates the entire AI pipeline — not just the output.

01
Get a real-world challenge
Messy PDFs, inconsistent logs, noisy text blobs — tasks that genuinely require AI to solve. No toy problems.
02
Build your AI pipeline
Write prompts, orchestration logic, and code. All LLM calls go through our SDK — every token is tracked and measured.
03
Get your Efficiency Report
Your code is evaluated across 8 dimensions: accuracy, prompt quality, rule adherence, efficiency, reliability, orchestration, code quality, and edge case handling.
the scoring system

Seven weighted signals.
One overall score.

The overall score is weighted exactly like the evaluator engine. Rule adherence is enforced as a hard cap gate.

◎
Accuracy · 35%
Output compared against ground truth with fuzzy matching for dates, names, numbers, and nested structures.
correctness vs expected structured output
⟡
Prompt Quality · 10%
How well you talked to the AI. Scored on clarity, specificity, structure, robustness, and grounding.
LLM-as-judge evaluates your prompt engineering
◇
Robustness · 15%
Pass rate under perturbed and adversarial inputs. Fragile solutions drop fast here.
stability under noisy and adversarial cases
⟐
Efficiency · 15%
Lower token usage and cost = higher score. Batch calls, avoid redundant context.
1 call, 420 tokens beats 6 calls, 2,864 tokens
◈
Reliability · 10%
Consistency across runs with noisy and perturbed inputs. Brittle solutions score low.
temperature=0 + robust parsing = high reliability
⬡
Orchestration · 10%
LLM integration quality: error handling, retry logic, output validation, separation of concerns.
try/except, JSON validation, modular code
⌬
Calibration · 5%
Confidence alignment with observed correctness. Overconfident wrong outputs are penalized.
confidence should match actual success rate
⊘
Rule Adherence Gate · hard cap
Weak schema or challenge-rule adherence caps overall score, even when other metrics look strong.
challenge rules are non-negotiable
